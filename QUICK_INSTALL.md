## 🔧 Troubleshooting

### "App not installed"
- Enable "Install from Unknown Sources"
- Check Android version (requires Android 7.0+)

### "Parse error"
- File may be corrupted, re-download
- Check device compatibility

### Maps not working
- Check internet connection
- Maps API key is configured
