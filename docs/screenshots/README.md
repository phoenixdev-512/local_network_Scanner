# Screenshots

This directory contains screenshots of the NetSentry application.

## Adding Screenshots

Screenshots should be in PNG format with the following naming convention:

- `dashboard.png` - Dashboard screen
- `security.png` - Security screen
- `network.png` - Network scanner screen
- `activity.png` - Activity monitor screen
- `settings.png` - Settings screen

## Recommended Size

- Width: 1080px (full phone width)
- Height: 2340px (full phone height) or cropped as needed
- Format: PNG
- Quality: High

## Capturing Screenshots

1. Run the app on a device or emulator
2. Navigate to the desired screen
3. Take screenshot using:
   - Device: Power + Volume Down
   - Emulator: Camera icon in toolbar
4. Copy to this directory
5. Rename appropriately
